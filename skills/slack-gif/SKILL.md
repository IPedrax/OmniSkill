# Slack GIF

> Slack-ready animated GIFs · OmniSkill Design crew

This capability is provided by **Slack GIF**, bundled with Claude Code — nothing to install.

## Use it

Invoke /slack-gif-creator and follow it. That skill is the authority here — this file only routes to it and adds the OmniSkill house rules below.

## House rules

Use it for short looping animations sized for Slack. Keep them small and legible at emoji scale — a GIF that needs a full-size preview to read has missed the format.

## If it is missing

It ships with Claude Code, so absence means bundled skills are disabled. Check the `disableBundledSkills` setting.
