# Word Documents

> Word docs, tracked changes · OmniSkill Legal crew

This capability is provided by **Word Documents**, bundled with Claude Code — nothing to install.

## Use it

Invoke /docx and follow it. That skill is the authority here — this file only routes to it and adds the OmniSkill house rules below.

## House rules

Use it to deliver contract redlines with tracked changes, which is the form counterparties actually review. Pair every redline with a short summary of what changed and why — a marked-up document with no rationale invites a rejection.

## If it is missing

It ships with Claude Code, so absence means bundled skills are disabled. Check the `disableBundledSkills` setting.
