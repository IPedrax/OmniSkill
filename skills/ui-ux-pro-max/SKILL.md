# UI/UX Pro Max

> Full design-system intel · OmniSkill Design crew

This capability is provided by **UI/UX Pro Max**, a personal skill in the user's `~/.claude/skills/` directory.

## Use it

Invoke /ui-ux-pro-max and follow it. That skill is the authority here — this file only routes to it and adds the OmniSkill house rules below.

## House rules

Start every design task here. It carries style catalogues, palettes, font pairings, and stack-specific guidance. Decide style, palette, and typography before any markup exists.

## If it is missing

This is a personal skill rather than a plugin, so it cannot be installed automatically as a dependency. If it is missing, either install it into `~/.claude/skills/ui-ux-pro-max/` or fall back to `/omniskill:frontend-design` and choose the direction explicitly.
