# Web Artifacts

> shadcn HTML artifacts · OmniSkill Design crew

This capability is provided by **Web Artifacts**, bundled with Claude Code — nothing to install.

## Use it

Invoke /web-artifacts-builder and follow it. That skill is the authority here — this file only routes to it and adds the OmniSkill house rules below.

## House rules

Use it for a self-contained shareable page — a dashboard, calculator, or one-pager. For a real application with routing and a build step, use `/omniskill:frontend-design` instead.

## If it is missing

It ships with Claude Code, so absence means bundled skills are disabled. Check the `disableBundledSkills` setting.
